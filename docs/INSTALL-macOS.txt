数学面试词汇 · macOS 1.3.0（build 5）

适用于 macOS 14 或更高版本，支持 Apple Silicon 与 Intel Mac。
解压后可将“数学面试词汇.app”拖入“应用程序”文件夹，再双击打开。
不要直接在网盘自动同步目录中运行.app，避免同步临时文件破坏签名；ZIP可正常保存。

当前应用使用临时签名，未经过 Apple Developer ID 签名或公证。
如果系统提示无法验证开发者，请先核对 GitHub 发布来源及 SHA-256。
仅在确认信任此项目后，使用系统“隐私与安全性”提供的单次打开选项。
不要关闭 Gatekeeper 或其他系统安全防护。

内置326条词汇、130条重点词汇，含英美音标、四选项检测和本地学习记录。
←／↑切换上一个词条，→／↓切换下一个；按当前筛选结果移动，首尾不循环。
检测用A–D或1–4作答，答后按Enter／→／↓继续；未答题不会跳过。
输入、选词、菜单及原生控件优先；长按不连续切词、不重复计分。
内置与Windows版相同的Kokoro自然语音：2328个美式、英式音频片段。
完整词组、所选完整单词及索引内连续词组可离线朗读，保留三档语速。
学习与发音不需要联网、首次下载、账号或语音模型，不向Google等服务发送朗读文本。
索引外的任意字母片段会提示音频缺失，不联网，也不切换系统语音。
音源声明与Apache 2.0许可随应用资源提供；Kokoro音频不是Google音频。

设置中的“软件更新”可联网检查GitHub正式版；仅在你点击时检查和下载。
下载完成后会校验SHA-256；点击“在文件夹中显示”，退出旧版后解压并替换应用。
校验后的ZIP添加互联网来源隔离标记；若无法添加，请改用发布页的浏览器下载。
不自动安装、运行或覆盖程序，不上传学习记录。SHA-256不代替发布者签名。
没有检查更新入口的1.2.0之前版本，请直接从GitHub手动下载当前桌面版。
1.2.0可在设置中检查更新；本次桌面版1.3.0不重建Android，Android仍为1.2.0。
程序更新不会自动清空学习记录。需要重置时请在应用设置中确认操作。
