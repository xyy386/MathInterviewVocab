数学面试词汇 · macOS 1.5.1（build 8）

适用于 macOS 14 或更高版本，支持 Apple Silicon 与 Intel Mac。
解压后可将“数学面试词汇.app”拖入“应用程序”文件夹，再双击打开。
不要直接在网盘自动同步目录中运行.app，避免同步临时文件破坏签名；ZIP可正常保存。

当前应用使用临时签名，未经过 Apple Developer ID 签名或公证。
如果系统提示无法验证开发者，请先核对 GitHub 发布来源及 SHA-256。
仅在确认信任此项目后，使用系统“隐私与安全性”提供的单次打开选项。
不要关闭 Gatekeeper 或其他系统安全防护。

内置326条词汇、130条重点词汇，含英美音标、四选项检测和本地学习记录。
1.5.1新增离线矢量公式排版：H₀、积分、求和、矩阵上标等不再显示为LaTeX命令。
公式整体选择，复制保留原始LaTeX（例如\(H_0\)）；混合复制保持顺序，超宽公式局部横向滚动。
搜索兼容H_0／H₀／H0。公式源码不会交给播放器；英文选词及完整词条朗读保持不变。
公式与字形许可见Contents/Resources/Math/SOURCES.md及同目录许可全文；运行不请求远程字体或数学CDN。
←／↑切换上一个词条，→／↓切换下一个；按当前筛选结果移动，首尾不循环。
检测用A–D或1–4作答，答后按Enter／→／↓继续；未答题不会跳过。
输入、选词、菜单及原生控件优先；长按不连续切词、不重复计分。
内置与Windows版相同的Kokoro自然语音：2328个美式、英式音频片段。
完整词组、所选完整单词及索引内连续词组可离线朗读，保留三档语速。
学习与发音不需要联网、首次下载、账号或语音模型，不向Google等服务发送朗读文本。
索引外的任意字母片段会提示音频缺失，不联网，也不切换系统语音。
音源声明与Apache 2.0许可随应用资源提供；Kokoro音频不是Google音频。

从1.3.0及更早版本升级，仍需最后一次退出旧版、解压并替换.app。
旧客户端本身没有安装器，不能仅靠修改GitHub跳过这一步。
此后在“设置→软件更新”主动检查，使用Sparkle原生更新窗口下载并确认“安装并重新启动”。
软件校验签名更新源和Ed25519归档签名，然后正常退出、替换并重新打开，不需自己解压。
保存失败会阻止退出；请先解决学习记录保存问题，再重试更新。
请将.app放入本地可写目录；只读磁盘映像、被转移的应用或权限不足时，按提示移入应用程序文件夹。
没有启动自动检查、自动下载或未经确认的安装，不上传学习记录。
1.4.0可沿用原有更新流程升级至1.5.0；新的加速和持久断点能力从1.5.0起生效。
设置中可选择智能多线加速、镜像优先或GitHub直连；第三方节点只接收公开更新请求。
下载中可继续学习，顶部进度条显示速度、百分比与当前线路；关闭设置不停止下载。
暂停、断网或退出保留断点，重开应用只读取本地缓存，需手动继续。
缓存位于~/Library/Caches/com.xingyiyao.MathInterviewVocab/Updates，与学习记录分离。
设置中的“清除下载缓存”需单独确认，不会删除收藏、错题、答题记录或发音偏好。
签名索引绑定不可变更新源与安装包，续传后重新计算完整SHA-256，Sparkle再验证归档签名。
更新签名不等于Apple Developer ID签名或公证，也不会消除首次安装的系统信任提示。
