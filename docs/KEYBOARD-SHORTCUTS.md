# 桌面快捷键

适用版本：macOS 1.3.0（build 5）／Windows 1.3.0。此功能纳入桌面版 v1.3.0；Android 保持 1.2.0。保留历史 GitHub 标签和附件，不迁移学习记录。

## 操作

| 页面 | 按键 | 操作 |
| --- | --- | --- |
| 词汇 | ←／↑ | 上一个筛选结果 |
| 词汇 | →／↓ | 下一个筛选结果 |
| 检测未答题 | A/B/C/D 或 1/2/3/4 | 提交从上到下对应的选项 |
| 检测已答题 | Enter／→／↓ | 下一题；最后一题查看结果 |

字母大小写、键盘数字区及数字小键盘均可使用。检测不会自动跳过未答题，也不提供返回上一题改答案。作答与鼠标点击共用记录逻辑，同一道题只计分一次。

词汇按当前搜索、科目、重点、收藏和错题筛选后的实际列表顺序切换，不按编号加减。首尾不循环，空结果不操作；没有选中词条时，→／↓ 选第一条，←／↑ 选最后一条。侧栏折叠时仍然生效，不会因此展开侧栏。切词停止旧发音、清除旧选区、详情回到顶部，展开的列表让当前词条保持可见。

## 与原生操作的关系

- 快捷键只在当前应用的前台窗口及当前模块生效，不是系统全局热键。
- 搜索输入、输入法组合、非空文本选区、菜单／弹窗、下拉框及侧栏分隔线优先。选词期间不切词；取消选区并离开输入控件后可继续导航。
- Shift＋方向键仍用于选词。Command／Ctrl／Alt 组合不会被解释为以上学习操作；Shift 仅允许字母大小写。原模块切换及设置快捷键不变。
- 一次按键只操作一次；长按产生的重复事件不连续切词、不重复提交或跳题。
- 可继续使用鼠标、滚轮及系统原生控件导航；Windows 的侧栏分隔线仍可用左右键调宽。

## 开发验证

新增测试覆盖按键映射、非连续编号／筛选顺序、边界、长按、窗口／焦点／选区保护和答题去重，并以实际键盘事件测试补充原有静态界面契约测试。测试使用隔离的学习记录，不向个人记录中写入验收答案。

本轮不使用 PD、虚拟机或模拟器。Windows 渲染器在 macOS 上运行的事件验收不等同于 Windows 实机测试；没有实际运行的设备或系统版本不得标记为已验证。
