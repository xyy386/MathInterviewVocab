# 数学面试词汇 v1.3.4 · Android 列表显示与闪卡/音标细节全面修复

本次更新将 Android 原生版升级至 **1.3.4（versionCode 6）**，集中修复并优化了词汇列表上滑残影、顶栏与底部导航栏纵向空间占用、回到顶部悬浮圆钮、检测重点词加粗、闪卡 3D 翻转方向与音标排版等 7 项界面与交互问题；Windows 1.3.0 与 macOS 1.3.0（build 5）保持不变，桌面用户继续使用 [v1.3.0 发布页](https://github.com/xyy386/MathInterviewVocab/releases/tag/v1.3.0) 的桌面安装包。

## Android 1.3.4（versionCode 6）更新内容

1. **修复列表上滑单词半透明残影与挤压显示不全 bug**：移除导致词条在科目吸顶栏下方产生透明淡化与高度挤压的上滑卡片堆叠缩放透明变换，词条滚动全程清晰完整。
2. **紧凑化顶部区域，大幅释放词汇列表可视空间**：将搜索框、遮挡自测开关与筛选按钮整合为单行紧凑工具栏，并将首屏学习概览收束为单行进度条（浏览下滑时自动收起），显著增加首屏可见词条数量。
3. **紧凑常驻底部导航栏**：重构移动端底部导航栏为紧凑高度单行图文胶囊栏，减少底部垂直空间占用。
4. **「回到顶部」升级为小圆按钮且仅在上滑时显示**：将原本遮挡右下角词条的宽胶囊按钮改为轻巧圆形图标按钮，且仅在用户向列表上方回滚时浮现、下滑浏览时自动隐藏。
5. **取消检测界面重点词汇加粗**：在词汇检测题面、四个选项及闪卡题面中统一使用标准字重，避免因“重点词加粗”泄露视觉特征。
6. **面试闪卡 3D 翻转方向对调并精简顶栏标签**：对调闪卡正面与背面的顺/逆时针 Y 轴 3D 翻转方向，并移除卡片上冗余的“面试闪卡 · 正面”与“面试闪卡 · 答案背面”标签。
7. **修复音标重音符跨行截断与字体渲染问题，精简关联词条**：新增 `VocabularyCore.displayIpa` 为词中重音符（`ˈ` / `ˌ`）注入非换行连接符并统一 `/.../` 斜杠包裹与 Sans-Serif 音标渲染；同时移除详情页“同科易混或递进术语”卡片中的音标显示，保持对比列表清爽。
