# 数学面试词汇 v1.3.2 · Android 深浅双主题与物理动效全面升级

本次更新将 Android 原生版升级至 **1.3.2（versionCode 4）**，全面重构视觉层次与 11 项移动端轻量化物理阻尼动效；Windows 1.3.0 与 macOS 1.3.0（build 5）保持不变，桌面用户继续使用 [v1.3.0 发布页](https://github.com/xyy386/MathInterviewVocab/releases/tag/v1.3.0) 的桌面安装包。

## Android 1.3.2（versionCode 4）更新内容

1. **主题切换（触点圆心扩散换页）**：新增学院深色夜读主题与暖纸浅色主题，点击顶栏或设置页切换时以手指触点为圆心做圆形扩散裁切换页，双层画面预加载、文字与卡片无变形缩放。
2. **拖拽排序（实时弹簧让位）**：学科浏览卡片与学习记录学科进度卡支持长按浮起拖动排序，其余条目实时弹簧动画让位，手指暂停时动画同步静止。
3. **批量勾选（错峰弹性放大）**：筛选面板支持一键“全选筛选 / 取消全选 / 清除筛选”，各筛选项从上到下依次错峰勾选，每项勾选伴随轻微弹性放大。
4. **滑杆吸附（惯性过冲 + 回弹吸附）**：朗读语速（`0.75× / 1.0× / 1.25×`）与检测题量（`10 / 20 / 50 / 全部`）升级为物理刻度吸附滑杆，拖滑杆松手后带速度惯性过冲并回弹吸附到最近刻度。
5. **文本展开（平滑拉伸 + 箭头 180° 旋转）**：词汇筛选面板、详情页学习提示、设置页更新说明及答题后解析卡片均采用柔和弹簧高度拉伸，右侧箭头同步旋转 `180°`，无突兀闪现。
6. **进度回弹（超调确认感）**：检测答题进度条与学科掌握度进度条在推进时先轻微超调（overshoot）再柔和回弹定格，强化完成确认感。
7. **开关联动（同组涟漪微震）**：点击检测方向、检测范围、默认口音或外观主题组内某一项时，同组其余开关按距离顺序产生轻微涟漪式阻尼微震，状态与功能不变。
8. **卡片删除（曲线飞入角落移除）**：在“仅我的收藏”视图中右滑（或左滑）词条卡片可沿抛物曲线飞向右上角移除区，飞行途中同步缩小、旋转并降低透明度。
9. **卡片堆叠（上滑停留压缩 + 浏览进度）**：上滑列表时顶部词条先短暂驻留并被后续词条逐步压缩堆叠，同时实时显示浏览进度。
10. **标签选择（选中放大 + 周边平移让位）**：横向学科标签栏、单词快捷点读胶囊与滑杆刻度标签在点击选中时轻微弹性放大，周边相邻标签自动向两侧平移让位。
11. **全局轻量化按压回弹**：所有核心卡片与按钮均配备柔和阻尼按压反馈。
