# 数学面试词汇 v1.3.3 · Android 信息密度与学习模式十项功能升级

本次更新将 Android 原生版升级至 **1.3.3（versionCode 5）**，围绕词汇浏览密度、遮挡自测、随身听连播、个人掌握轨迹、关联概念对比、面试闪卡与听音辨义等 10 项核心学习场景进行了全面功能充实；Windows 1.3.0 与 macOS 1.3.0（build 5）保持不变，桌面用户继续使用 [v1.3.0 发布页](https://github.com/xyy386/MathInterviewVocab/releases/tag/v1.3.0) 的桌面安装包。

## Android 1.3.3（versionCode 5）更新内容

1. **列表项音标直显 + 一键朗读 🔊 + 一键收藏 ⭐**：每个词汇列表卡片直接展示当前默认口音音标（US / UK）与连对进度，右侧提供独立“🔊 一键朗读”与“⭐ 一键收藏”按钮，无需反复进出详情页即可高频听音与收藏。
2. **列表遮挡自测模式（遮英文 / 遮中文 / 点击显词）**：词表顶部新增 `👁 完整显示`、`🙈 遮英文自测`、`🙈 遮中文自测` 三态切换栏，遮挡状态下点击单条词卡即可原地显词核对并支持重遮。
3. **紧凑顶部搜索栏 + 今日学习概览看板**：将筛选面板收折进搜索框右侧的紧凑筛选按钮，释放纵向列表视野；同时在列表首屏增加带掌握率圆环、重点词进度、“继续上次浏览”、“⚡ 快测 10 题”与“🔥 专练错题”的今日学习看板。
4. **详情页本词个人掌握轨迹 + 手动熟练度控制**：详情页新增“本词掌握轨迹与熟练度”卡片，展示三点式连对进度（`● ● ○`）、本词历史作答次数与正确率，并支持手动“标为已掌握 / 移出已掌握”与“加入待复习 / 移出待复习”。
5. **详情页同科关联概念对比**：将原本千篇一律的静态提示升级为动态计算的“同科关联概念对比”，自动匹配最多 4 个同科易混或递进术语（支持直接听音或点击跳转对比）。
6. **随身听连续播读模式（Auto-Play 磨耳朵）**：列表顶栏与详情页均提供“🎧 连播”开关，开启后从当前词条起按“美式发音 → 停顿 → 英式发音 → 下一词”自动顺序播读并同步高亮。
7. **面试闪卡（Flashcard）3D 翻转自测模式**：检测页新增“面试闪卡翻转自测”题型，题面先展示中/英文或发音提示供主动口述回忆，点击卡片 3D 翻面核对完整音标、发音与释义后，由用户自评“记错了·需复习”或“熟练答出”。
8. **听音辨义（听力题）检测方向**：检测方向新增“🔊 听音辨义（听英文发音 → 选中文概念）”，切题后自动播放英文离线发音并隐藏英文拼写，专门强化全英文数学面试听力反应。
9. **全词库四态环形分布图 + 学科三态堆叠进度条**：学习记录页顶部新增 Canvas 四态环形图（已掌握 / 学习巩固中 / 待复习错题 / 尚未检测），学科卡片升级为“掌握绿 + 学习蓝 + 错题红”三态分段进度条。
10. **待复习错题 / 我的收藏 / 最近答题流水三合一面板**：学习记录页底部整合三大页签，支持右滑卡片飞出移出错题或取消收藏，并可按时间倒序查阅最近 30 条答题明细。
