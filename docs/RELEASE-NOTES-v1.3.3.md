# 数学面试词汇 v1.3.3 · Android 信息密度与学习模式升级

本次更新将 Android 原生版升级至 **1.3.3（versionCode 5）**，围绕词汇浏览便捷操作、遮挡自测、个人掌握轨迹、关联概念对比、面试闪卡与统计分布等核心学习场景进行了功能充实，并保持统一清爽的学院蓝视觉风格；Windows 1.3.0 与 macOS 1.3.0（build 5）保持不变，桌面用户继续使用 [v1.3.0 发布页](https://github.com/xyy386/MathInterviewVocab/releases/tag/v1.3.0) 的桌面安装包。

## Android 1.3.3（versionCode 5）更新内容

1. **列表项一键朗读 🔊 + 一键收藏 ⭐**：每个词汇列表条目右侧直接提供独立的“🔊 一键朗读”与“⭐ 一键收藏”按钮，并展示连对进度徽章（`连对 X/3`），无需反复进出详情页即可高频听音与收藏。
2. **列表遮挡自测模式（遮英文 / 遮中文 / 点击显词）**：词表顶部新增 `👁 完整显示`、`🙈 遮英文自测`、`🙈 遮中文自测` 三态切换栏，遮挡状态下点击单条词条即可原地显词核对并支持重遮。
3. **紧凑顶部搜索栏 + 首屏学习概览看板**：将筛选面板收折进搜索框右侧的紧凑筛选按钮，释放纵向列表视野；同时在列表首屏增加带掌握率圆环、重点词进度与错题/收藏统计的学习概览卡片。
4. **详情页本词个人掌握轨迹 + 手动熟练度控制**：详情页新增“本词掌握轨迹与熟练度”卡片，展示三点式连对进度（`● ● ○`）、本词历史作答次数与正确率，并支持手动“标为已掌握 / 移出已掌握”与“加入待复习错题 / 移出待复习错题”。
5. **详情页同科关联概念对比**：将原本静态提示升级为动态计算的“同科关联概念对比”，自动匹配最多 4 个同科易混或递进术语（支持直接听音或点击跳转对比）。
6. **面试闪卡（Flashcard）3D 翻转自测模式**：检测页新增“面试闪卡翻转自测”题型，题面先展示中/英文供主动口述回忆，点击卡片 3D 翻面核对完整音标、发音与释义后，由用户自评“记错了·需复习”或“熟练答出”。
7. **全词库四态环形分布图 + 学科三态堆叠进度条**：学习记录页顶部新增 Canvas 四态环形图（已掌握 / 学习巩固中 / 待复习错题 / 尚未检测），学科卡片升级为“掌握绿 + 学习蓝 + 错题红”三态分段进度条。
8. **待复习错题 / 我的收藏 / 最近答题流水三合一面板**：学习记录页底部整合三大页签，支持右滑卡片飞出移出错题或取消收藏，并可按时间倒序查阅最近 30 条答题明细。
