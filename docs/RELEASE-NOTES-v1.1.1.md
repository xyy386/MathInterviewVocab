# 数学面试词汇 v1.1.1

Windows 与 macOS 双平台正式首发，不是预发布版。

## 下载附件

| 文件 | 内容 |
| --- | --- |
| `MathInterviewVocab-Windows-x64-v1.1.1.zip` | Windows 10/11 x64，应用 1.1.1 |

请下载平台 ZIP 并完整解压，不要将 GitHub 自动生成的 Source code 当作应用。完整入口见 [发布页](https://github.com/xyy386/MathInterviewVocab/releases/tag/v1.1.1)。

## 本次发布

- 两平台均包含 326 条数学专业面试词汇、130 条重点、中文释义和英美 IPA。
- 提供词汇搜索、科目／重点／收藏／错题筛选、双向四选一检测及本地学习记录。
- Windows 1.1.1 按 Mac 对齐导航、侧栏、卡片、排版和独立设置窗口；设置修改立即生效。
- 支持完整词组和所选完整单词朗读，选择文字本身不会自动播放；美式／英式及三档语速可独立选择。
- 以 MIT 许可公开项目原创代码，并保留第三方组件、音源和内容来源声明。

## 平台差异与注意事项

Mac 使用 Google 在线发音增强，失败后回退到同口音系统语音；主动请求在线朗读时会发送对应英文。Windows 使用随包内置的 Kokoro 自然语音，2328 个音频片段，无需联网或首次下载。两平台不共享学习数据，也没有账号或云同步。

当前 Mac 成品为 ad-hoc 临时签名，没有 Developer ID 签名或 Apple 公证；Windows 成品没有商业代码签名。请核对来源和校验和，不要关闭系统全局安全防护。系统字体、原生菜单和确认对话框会有平台差异。

Windows 实机运行已由用户验证。Mac 的既有验证记录包含 25 项自动化测试，Windows 项目包含 68 项自动化测试；不据此宣称所有系统版本、硬件和缩放组合均已验证。公开验收范围见 [发布检查说明](https://github.com/xyy386/MathInterviewVocab/blob/v1.1.1/docs/RELEASE-CHECKS.md)。

本次为发布补充许可、说明与 ZIP 封装，不修改两平台应用的可执行程序。
