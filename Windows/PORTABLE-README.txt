数学面试词汇 · Windows 1.3.0

使用方法
1. 将整个 ZIP 解压到一个文件夹。不要在压缩包内直接运行。
2. 双击“数学面试词汇.exe”。请保留旁边的 DLL、resources 等配套文件。
3. 不需要安装 Python、Node.js 或其他开发环境。

适用 Windows 10/11 64 位 Intel / AMD 电脑，不支持 Windows 7/8 和 32 位系统。

词库、英美音标、自然语音、检测和学习记录均可离线使用。无需账号、首次下载或联网激活。
语音为随包内置的开源自然语音音频，不是 Google 在线服务或离线 Google 模型。
支持完整词组、其中的单词及内置连续词组选区。请选中完整单词；不在资源内的任意字母片段会提示无内置音频，不会联网。

主要功能：词汇 / 检测 / 学习记录；科目与重点、收藏、错题筛选；英美发音及 IPA；0.75× / 1× / 1.25×；收藏与错题、掌握状态独立保存。
快捷键：Ctrl+1/2/3 切换模块，Ctrl+, 打开设置。
词汇页 ←/↑ 上一个、→/↓ 下一个，按当前搜索和筛选顺序移动，首尾不循环；收起侧栏仍可切词。
检测时 A/B/C/D 或 1/2/3/4（含数字小键盘）选择答案；作答后 Enter/→/↓ 下一题，最后一题进入结果页。
不能跳过未答题，也不能返回已提交题目改答案。长按不会连跳或重复计分。
输入框、输入法、选词、菜单和侧栏分隔线优先，选中文字不会自动发音；取消选区并离开输入控件后可继续快捷导航。

软件更新
在“设置 → 软件更新”中点击“检查更新”，查看 GitHub 最新正式版。
发现新版后，可点击“下载更新”。软件会下载对应的 Windows x64 ZIP 并校验 SHA-256 与文件大小。
校验通过后会显示下载文件夹；请退出旧版，把新 ZIP 完整解压到新文件夹后运行新版。
不要在旧版仍运行时覆盖 EXE，也不要删除本机学习记录目录。更新不会修改或清空学习记录及发音设置。
支持取消和重试；不会静默安装、执行更新包，也不会在启动时自动联网。
词库与发音始终离线；仅检查和下载更新时联网。更新请求不发送学习记录、账号、Cookie 或令牌。
SHA-256 校验用于验证下载完整性，不等同于商业代码签名或独立的数字签名。

记录保存在 %LOCALAPPDATA%\MathInterviewVocab\progress.json。
更换软件解压位置、更新软件或删除解压文件夹，不会自动清空学习记录。
Mac 与 Windows 的记录独立保存，不提供网络同步。重置请使用软件设置，并阅读确认提示。

本包未购买商业代码签名证书，Windows 可能显示未知发布者警告。请核对来源与提供的 SHA-256；不要关闭系统安全防护。
旧版 Windows 实机运行曾由用户验证；1.3.0 本轮通过自动化测试及 macOS 宿主 Electron 页面事件验收，尚未做新的 Windows 实机验收，不使用 PD 或模拟器。
