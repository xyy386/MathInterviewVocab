数学面试词汇 · Windows 全离线版

使用方法
1. 将整个 ZIP 解压到一个文件夹。不要在压缩包内直接运行。
2. 双击“数学面试词汇.exe”。请保留旁边的 DLL、resources 等配套文件。
3. 不需要安装 Python、Node.js 或其他开发环境。

适用 Windows 10/11 64 位 Intel / AMD 电脑，不支持 Windows 7/8 和 32 位系统。

词库、英美音标、自然语音、检测和学习记录均可离线使用。无需账号、首次下载或联网激活。
语音为随包内置的开源自然语音音频，不是 Google 在线服务或离线 Google 模型。
支持完整词组、其中的单词及内置连续词组选区。请选中完整单词；不在资源内的任意字母片段会提示无内置音频，不会联网。

主要功能：词汇 / 检测 / 学习记录；科目与重点、收藏、错题筛选；英美发音及 IPA；0.75× / 1× / 1.25×；收藏与错题、掌握状态独立保存。
快捷键：Ctrl+1/2/3 切换模块；检测时 1/2/3/4 选择答案；作答后 Enter 下一题。

记录保存在 %LOCALAPPDATA%\MathInterviewVocab\progress.json。
更换软件解压位置、更新软件或删除解压文件夹，不会自动清空学习记录。
Mac 与 Windows 的记录独立保存，不提供网络同步。重置请使用软件设置，并阅读确认提示。

本包未购买商业代码签名证书，Windows 可能显示未知发布者警告。请核对来源与提供的 SHA-256；不要关闭系统安全防护。
Windows 实机运行已由用户验证；不代表所有系统版本、设备和缩放比例均已全面验证。
